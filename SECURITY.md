# Security

Use the repository's **Security → Report a vulnerability** option when private reporting is enabled. Otherwise contact the repository owner privately before sharing sensitive details.

Report account isolation problems, exposed credentials or access to someone else's profile/photos privately. Do not include passwords, tokens or private wardrobe data in public issues.

The browser uses only public Supabase configuration. Groq and database service credentials belong on the server. Cloud account isolation and shared AI quota controls remain release gates; this project is currently a testing build.
